# Zadání
FitPlanner – Inteligentní plánovač tréninku a jídelníčku

FitPlanner je webová aplikace určená pro plánování a evidenci sportovních aktivit a stravování. Uživatelům umožní vytvářet a upravovat tréninkové plány, sestavovat jídelníčky, sledovat příjem kalorií a makroživin a vyhodnocovat dlouhodobý pokrok. Součástí aplikace bude AI asistent, který na základě požadavků zadaných přirozeným jazykem dokáže upravovat tréninkové plány a jídelníčky. Aplikace bude rovněž využívat externí službu pro získávání nutričních informací o potravinách. Cílem projektu je nabídnout uživatelům jednotné a přehledné prostředí, které jim usnadní plánování tréninku i stravování a přizpůsobování jejich individuálním potřebám.
